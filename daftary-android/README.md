# دفتري — Daftary

تطبيق أندرويد عربي لإدارة مبيعات السيارات بالتقسيط.

## النسخة الأولية
- تسجيل عقد باسم المشتري ونوع السيارة فقط كحقول إلزامية.
- السعر والدفعة المقدمة وعدد الأقساط اختيارية.
- تخزين محلي دائم عبر SQLite.
- لوحة إجماليات المبيعات والتحصيل والرصيد المتبقي.
- تسجيل دفعات وتحديث الرصيد.
- بحث بالاسم أو نوع السيارة.
- واجهة RTL مستوحاة من تطبيقات iOS.

## APK
يُبنى تلقائياً عبر GitHub Actions. افتح تبويب Actions ثم Daftary Android APK لتحميل Artifact باسم Daftary-Android-APK.

هذه نسخة أولية للاختبار؛ التقارير التفصيلية، العقود المطبوعة، جداول الاستحقاق والنسخ الاحتياطي مراحل تالية.
